# Lab 4a — Struktura wielomianu wielu zmiennych

## Reprezentacja

Wielomian w `R[x, y, z, ...]` jest przechowywany jako słownik Python:

```
{ krotka_wykładników: współczynnik }
```

**Klucz** to `tuple` liczb całkowitych nieujemnych — wykładniki przy kolejnych zmiennych.  
**Wartość** to współczynnik rzeczywisty (`int` lub `float`).

### Przykład

```
f(x, y, z) = 4x³y² − 2xy²z + z⁴ + 1
```

```python
f = {
    (3, 2, 0):  4,
    (1, 2, 1): -2,
    (0, 0, 4):  1,
    (0, 0, 0):  1,
}
```

Wielomian zerowy to pusty słownik `{}`.  
Liczba zmiennych jest niejawna — wynika z długości krotek.

---

## Funkcje

### `poly_clean(f)`
Usuwa wyrazy o zerowym współczynniku. Wywoływana wewnętrznie po każdej operacji, żeby słownik nie rósł ze śmieciami.

### `poly_add(f, g)` / `poly_sub(f, g)`
Dodawanie i odejmowanie. Dla każdego wykładnika z `g` dodajemy (lub odejmujemy) jego współczynnik do odpowiedniej pozycji w kopii `f`. Jeśli wykładnik nie istnieje w `f`, domyślnie bierzemy 0.

```python
result[exp] = result.get(exp, 0) + c   # dla add
```

### `poly_mul(f, g)`
Mnożenie. Każdy wyraz `f` mnożymy z każdym wyrazem `g`:
- wykładniki **sumujemy** składowo (odpowiada mnożeniu potęg: `x^a * x^b = x^(a+b)`),
- współczynniki **mnożymy**.

Złożoność: O(|f| · |g|) pod względem liczby wyrazów.

### `poly_mul_monomial(f, exp_m, coeff_m)`
Uproszczone mnożenie przez jeden jednomian `coeff_m * x^exp_m`. Szybsze niż `poly_mul`, bo tylko jedna pętla. Używane intensywnie w `PolynomialReduce`.

### `poly_scale(f, scalar)`
Skalowanie wszystkich współczynników przez skalar. Specjalny przypadek `poly_mul_monomial` z wykładnikiem zerowym.

### `poly_degree(f)`
Stopień wielomianu = maksymalna suma wykładników wśród wszystkich wyrazów.  
Dla wielomianu zerowego zwraca `-1`.

```python
deg(4x³y² − 2xy²z + z⁴ + 1) = max(5, 4, 4, 0) = 5
```

### `poly_eval(f, values)`
Oblicza wartość wielomianu w punkcie. `values` to lista/krotka wartości kolejnych zmiennych.  
Dla każdego wyrazu liczymy `coeff * x0^e0 * x1^e1 * ...` i sumujemy.

### `poly_str(f, var_names=None)`
Zamienia słownik na czytelny ciąg znaków.  
Wyrazy sortowane malejąco według `(stopień całkowity, krotka wykładników)` — daje naturalny porządek "od największego".  
Domyślne nazwy zmiennych: `x, y, z, w, ...` (kolejne litery alfabetu).

---

## Własności struktury

| Cecha | Opis |
|---|---|
| Zwartość | Przechowywane tylko niezerowe wyrazy |
| Ogólność | Działa dla dowolnej liczby zmiennych — wystarczy zmienić długość krotek |
| Operacje na wyrazach | Dodawanie wykładników ↔ mnożenie jednomianów; odejmowanie ↔ dzielenie |
| Brak porządku | Słownik nie ma kolejności; porządek na jednomianach definiowany osobno (Lab 4b) |
